## 🌟 About UniHub

**UniHub** is an AI-powered student campus platform that brings everything a student needs into one place.

From checking attendance, lecture schedules, assignments, results, and academic progress to interacting with an AI assistant, discovering campus events, buying or selling study materials, and connecting with fellow students, UniHub simplifies everyday campus life through intelligent automation.

Built using modern web technologies and Large Language Models (LLMs), UniHub delivers a personalized, smart, and connected student experience.
